# NEXT HOST — Simulado PIM II

Simulado estático com 36 questões técnicas, modo rápido de 15 questões, alternativas embaralhadas, feedback, referências ao código e revisão de erros.

## Uso imediato
Abra `index.html` em um navegador. Não é necessário instalar nada, nem ter internet para responder ao questionário. Os links de referência ao GitHub exigem internet.

## Publicação no GitHub Pages
1. Crie um repositório público novo, por exemplo `pim2-simulado`.
2. Envie `index.html` e, opcionalmente, este README à raiz da branch `main`.
3. Em Settings > Pages, selecione Deploy from a branch, `main`, `/ (root)` e Save.
4. Quando o Pages informar que o deploy foi concluído, copie o endereço exibido e envie ao grupo.

Não publique arquivos do projeto original. O simulado não contém a senha administrativa nem depende de banco de dados. As referências apontam para o commit oficial b6cf1df6daad3db7025908757b27879f8d241fbf.
